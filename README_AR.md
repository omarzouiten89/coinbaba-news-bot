# بوت النشر ديال COINBABA

البوت كيراقب قنوات Telegram والمواقع الإخبارية، وأي خبر جديد كيعاود يكتبو بالعربية الفصحى
وكينشرو دغيا في قناتك مع الصورة الأصلية، كرسالة جديدة (بلا "Forwarded from" وبلا روابط أو مصادر).

## شنو كيدير بالضبط
- **المصادر:** القنوات اللي في `config.yaml` (بحال @WatcherGuru) + Cointelegraph + CoinDesk.
- **التصفية:** كيحيد الإعلانات، المكرر (حتى إلا تكتب بطريقة أخرى)، الأخبار القديمة (أكثر من 6 ساعات)، وداكشي اللي ما عندو علاقة بالأسواق.
- **الكتابة:** Gemini (مجاني) كيعاود يصيغ الخبر بالفصحى، وكيحافظ على الأرقام.
- **الحد:** 60 منشور فالنهار (توقيت المغرب).
- **الأمان:** حساب Telegram ديالك كيقرا فقط. النشر كيديرو البوت.

## الملفات
| الملف | الدور |
|---|---|
| `config.yaml` | القنوات، المواقع، الحد اليومي، القناة اللي ينشر فيها |
| `.env` | المفاتيح السرية (أنت اللي كتعمرو، ما تشاركوش) |
| `data/` | قاعدة البيانات، السجل (bot.log)، وملف الدخول `reader.session` (سري) |

## خطوات التشغيل (مرة وحدة)
1. **تثبيت المكتبات:**
   ```bash
   python3 -m venv .venv && source .venv/bin/activate && pip install -r requirements.txt
   ```
2. **المفاتيح:** نسخ `.env.example` لملف جديد سميتو `.env` وعمّرو بيدك.
3. **ربط حساب القراءة:** `python3 login.py` (غادي يطلب الرقم والكود اللي كيوصلك من Telegram).
4. **رقم القناة:** زيد البوت Admin في القناة التجريبية، نشر فيها أي رسالة، ومن بعد:
   `python3 run.py find-channel` وحط الرقم في `config.yaml` عند `target_channel`.
5. **تجربة بلا نشر:** `python3 run.py test-rss` كيطبع ليك شكل المنشورات.
6. **التشغيل:** خلي `DRY_RUN=1` في `.env` باش تشوف فقط، ومن بعد بدلو لـ `DRY_RUN=0` وشغّل `python3 run.py`.

## الخدمة فالخلفية (الـ Mac)
البوت مثبت كخدمة سميتها `com.coinbaba.newsbot`: كيخدم بوحدو، كيعاود يشعل إلا طاح، وكيبدا ملي تدخل للـ Mac.
- **توقيف:** `launchctl bootout gui/$(id -u)/com.coinbaba.newsbot`
- **تشغيل من جديد:** `launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/com.coinbaba.newsbot.plist`
- **إعادة التشغيل بعد تبديل config.yaml:** `launchctl kickstart -k gui/$(id -u)/com.coinbaba.newsbot`
- **السجل:** `data/bot.log`

## زيادة أو حذف قناة
عدّل اللائحة `telegram_channels` في `config.yaml`، وعاود شغّل البوت.
خاص حساب القراءة يكون **داخل** للقناة من التيليفون ديالك.

## 📘 النشر في صفحة فيسبوك COINBABA
البوت كينشر نفس منشورات القناة (الأخبار المهمة، التحليلات، ملخص الصباح، المعلومات) في الصفحة،
**بلا روابط وبلا @**، مع 3 حتى 5 هاشتاغات. الاستطلاعات وأفكار التداول ما كيتنشروش فـ فيسبوك.
- **الستوري:** كل منشور فيه صورة كيتزاد حتى فـ Story ديال الصفحة (`stories: true`).
- **الحدود** (`config.yaml` > `facebook`): 5 فالنهار، ساعة بين خبرين، غير الأخبار اللي أهميتها 7+ من 10.
  العدد كيتحسب من الصفحة نفسها، باش Mac و GitHub ما يتجاوزوش الحد مع بعض.
- **المفاتيح:** `python3 set_key.py fb_page_id` و `python3 set_key.py fb_page_token`،
  وزيدهم حتى فـ GitHub > Settings > Secrets بنفس السمية (`FB_PAGE_ID` و `FB_PAGE_TOKEN`).
- **التجربة:** `python3 run.py facebook-check` (كيقرا سمية الصفحة بلا ما ينشر)، ومن بعد `enabled: true`.
- أي مشكل فـ فيسبوك ما كيوقفش النشر فـ Telegram، وكيوصلك تنبيه.
